## Selected Open-Source & Hardware Projects

### Real-Time Telemetry & Edge AI
- **[`hdhr-sports-tracker`](https://github.com/mikeheneka/hdhr-sports-tracker)** — Edge-computed, sub-second NFL broadcast telemetry and live web dashboard running on Apple Silicon. Ingests uncompressed Over-The-Air (OTA) television from an HDHomeRun tuner, extracts live play-by-play closed captions via `ccextractor`, runs computer vision / Tesseract OCR on broadcast scorebugs, and serves a real-time JSON API & SVG field visualizer.

### Embedded Hardware, RF & Local Systems
- **[`kids-tv`](https://github.com/mikeheneka/kids-tv)** — Child-friendly Live TV player for Raspberry Pi and Linux desktops that auto-discovers local SiliconDust HDHomeRun OTA tuners, filters by live antenna signal quality, and streams with hardware-accelerated `mpv` and `PyQt5`.
- **[`arduino-labs`](https://github.com/mikeheneka/arduino-labs)** — Arduino Uno (`ATmega328P`) hardware sketches paired with a real-time **Rust** (`Axum` + `SQLite`) serial telemetry collector and live web dashboard.
- **[`OpenClaw`](https://github.com/mikeheneka/OpenClaw)** — Lightweight Python CLI utility for outbound HTTP latency and toolchain sanity verification.
